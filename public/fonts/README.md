# Galan Font Directory

Place your `galan.woff2`, `galan.ttf`, `Galan.woff2`, or `Galan.ttf` font files in this folder.
The website's `@font-face` definition in `app/globals.css` and `--font-galan-custom` variable will automatically link to and display the authentic Galan font for the hero title.
If the file is not yet placed, the system gracefully falls back to `Space Grotesk`.
